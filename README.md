# Air Canvas Gesture Studio

## Project Overview

Air Canvas Gesture Studio is a real-time hand gesture recognition system developed using Python, OpenCV, and MediaPipe.

The project allows users to interact with a virtual canvas using hand gestures captured through a webcam. Users can draw, select colours, erase drawings, navigate PDF documents, and perform other canvas operations without depending on a traditional mouse or keyboard for these interactions.

## Features

- Real-time hand gesture recognition
- Webcam-based hand tracking
- Gesture-based drawing on a virtual canvas
- Multiple colour selection
- Eraser functionality
- Undo and Redo options
- PDF document navigation
- Image support
- Save and export functionality

## Technologies Used

- Python
- OpenCV
- MediaPipe
- NumPy
- PyMuPDF

## Requirements

- Python
- Webcam
- Required Python libraries listed in `requirements.txt`

## Installation

1. Clone or download this repository.
2. Open the project folder in the terminal.
3. Install the required libraries:

   ```bash
   py -m pip install -r requirements.txt
   ```

## How to Run

Run the following command in the terminal:

```bash
py Air_Canvas_Gesture_Studio.py
```

**Note:** If your Python file has a different name, replace `Air_Canvas_Gesture_Studio.py` with its actual filename.
